1. Introduction to Arrays

An array is a fixed-size sequential collection of elements of the same data type. Instead of declaring individual variables, such as number0, number1, ..., number99, you declare one array variable such as numbers and use numbers[0], numbers[1], ..., numbers[99] to represent individual variables.

  • Advantages: Code optimization, ease of traversing, ease of sorting/searching.
  • Disadvantages: Fixed size (static). You cannot change the size of the array once it is created (unless using dynamic memory allocation like malloc).

2. Declaration & Initialization

To declare an array in C, specify the data type, the name of the array, and the number of elements it can hold in square brackets.

data_type array_name[array_size];

Initialization Methods

You can initialize arrays at the time of declaration in several ways:

// 1. Declare and initialize with specific size
int ages[5] = {21, 22, 24, 25, 27};

// 2. Initialize without specifying size (Compiler calculates it)
int scores[] = {90, 85, 88, 92}; 

// 3. Partial initialization (Remaining elements become 0 automatically)
int marks[5] = {10, 20}; // Array becomes: {10, 20, 0, 0, 0}

// 4. Initialize all elements to 0
int counters[10] = {0};

3. Accessing Elements

Array elements are accessed using an index. C arrays are 0-indexed, meaning the first element is at index 0, and the last element is at index size - 1.

#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    
    // Accessing elements
    printf("First element: %d\n", arr[0]);
    printf("Third element: %d\n", arr[2]);
    
    // Modifying elements
    arr[1] = 99;
    printf("Modified Second element: %d\n", arr[1]);
    
    return 0;
}
Output: First element: 10 Third element: 30 Modified Second element: 99
⚠️ Out of Bounds Warning: C does NOT check if your index is valid. If you declare int arr[3] and try to access arr[10], the compiler won't stop you. It will access garbage memory, which can crash your program (Segmentation Fault).

4. The sizeof() Trick for Array Length

Unlike languages like Java or Python, C arrays do not have a built-in .length property. To find how many elements are in an array, you divide the total size of the array by the size of one element.

#include <stdio.h>

int main() {
    int arr[] = {15, 25, 35, 45, 55, 65, 75};
    
    // Total bytes of array / bytes of one integer
    int length = sizeof(arr) / sizeof(arr[0]);
    
    printf("The array has %d elements.\n", length);
    
    // Using length to loop through the array
    for(int i = 0; i < length; i++) {
        printf("%d ", arr[i]);
    }
    
    return 0;
}

5. Memory Representation

Arrays are stored in contiguous memory locations. The array name itself acts as a pointer to the base address (the address of the first element).

Element arr[0] arr[1] arr[2] arr[3]
Value 10 20 30 40
Memory Address (Assumes 4-byte int) 0x7ffd00 0x7ffd04 0x7ffd08 0x7ffd0c 
#include <stdio.h>

int main() {
    int arr[3] = {10, 20, 30};
    
    for(int i = 0; i < 3; i++) {
        // %p is used to print memory addresses
        printf("Address of arr[%d]: %p\n", i, &arr[i]);
    }
    return 0;
}

6. Multidimensional Arrays

C supports multidimensional arrays. The simplest form is the two-dimensional array, essentially an array of arrays (a matrix).

#include <stdio.h>

int main() {
    // 2 rows, 3 columns
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };
    
    for(int i = 0; i < 2; i++) {
        for(int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n"); // New line after each row
    }
    return 0;
}

7. Character Arrays (Strings)

In C, strings are simply arrays of characters ending with a special null character '\0'. This null character tells C where the string ends.

#include <stdio.h>

int main() {
    // Method 1: C automatically adds the '\0' at the end
    char greeting[] = "Hello"; 
    
    // Method 2: Manually adding '\0'
    char name[] = {'J', 'o', 'h', 'n', '\0'}; 
    
    printf("%s, %s!\n", greeting, name);
    
    // Notice the sizes:
    printf("Size of greeting: %lu bytes\n", sizeof(greeting)); // Outputs 6 (H-e-l-l-o + \0)
    
    return 0;
}

8. Passing Arrays to Functions

When you pass an array to a function, you are passing the memory address of the first element (pass by reference). This means changes made inside the function affect the original array.

Note: Because arrays "decay" into pointers when passed to functions, the sizeof(arr)/sizeof(arr[0]) trick does not work inside functions. You must pass the size as a separate argument. 
#include <stdio.h>

// The function takes the array and its size
void modifyArray(int arr[], int size) {
    for(int i = 0; i < size; i++) {
        arr[i] = arr[i] * 2; // Double the values
    }
}

int main() {
    int nums[] = {1, 2, 3, 4};
    int size = sizeof(nums)/sizeof(nums[0]);
    
    modifyArray(nums, size);
    
    for(int i = 0; i < size; i++) {
        printf("%d ", nums[i]);
    }
    return 0;
}
Output: 2 4 6 8

9. Pointers and Arrays (Advanced)

In C, array names and pointers are deeply linked. The name of the array evaluates to a pointer to its first element: arr == &arr[0].

You can use Pointer Arithmetic to navigate arrays without using square brackets.

#include <stdio.h>

int main() {
    int arr[] = {10, 20, 30, 40};
    int *ptr = arr; // ptr points to arr[0]
    
    // arr[i] is identical to *(arr + i)
    printf("arr[0] is: %d\n", *ptr);         // 10
    printf("arr[1] is: %d\n", *(ptr + 1));   // 20
    printf("arr[2] is: %d\n", *(arr + 2));   // 30
    
    return 0;
}

10. Variable Length Arrays (VLA)

Introduced in C99, VLAs allow you to define the size of an array using a variable at runtime. (Note: These are allocated on the Stack, so don't make them too large!)

#include <stdio.h>

int main() {
    int n;
    printf("Enter number of elements: ");
    // Assume user enters 5
    scanf("%d", &n);
    
    // Array size determined at runtime
    int vla_array[n]; 
    
    for(int i = 0; i < n; i++) {
        vla_array[i] = i * 10;
        printf("%d ", vla_array[i]);
    }
    
    return 0;
}
